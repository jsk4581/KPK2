## 3. 핵심 루프 (뇌가 하는 일)

1. **알기 (Profiler)**: 이력서·포트폴리오·퍼블리싱 → 커리어 자본 그래프.
2. **위기 감지 → 인터뷰 (Goal Coach)**: "일이 줄었다" 신호 또는 사용자 질문 → 저장해 둔 영감(YouTube·링크·메모)을 읽고 질문 1개씩 → 목표 문장을 사용자가 확인.
3. **계획 (Planner)**: 사용자가 기간 설정(예: 1년 중 3개월 준비) → 12주 게이트 4개(Fit·Proof·Market·Ready) → 월 → 주 3행동(≤30분, 요일) → 하루 1행동.
4. **기록 → 판단 (State + Monitor)**: 자동 라이프로그가 행동을 증거로 연결 → 계획 대비 진척·위반·이탈 위험 계산 → 근본 제약 1개만 짚는다.
5. **가이드 (Guide)**: 컨디션 낮으면 10분짜리로 줄이고 다음 날로 이동, 삭제·비난 없음. 주간 리뷰(월요일 fresh start)로 재계획.
6. **취업 (Evidence)**: 완료 행동 → 증거 선반 → 이력서 bullet·포트폴리오 → 준비도 점수 → 지원 단계.

로직 상세는 `ALGORITHM_DESIGN.md` §2–§7 (공식·임계값·의사코드·LLM 계약).

- **같은 코어, 두 껍데기**: 웹 API와 MCP 서버가 `brain-core.js` 하나를 공유 → "어디에나 임베딩"을 코드로 증명.
