- **축 1 — 전문성 전이형 커리어 경로 제안**: 가장 가까운 것은 **Google Career Dreamer**(경험·스킬·관심 → 커리어 맵, 무료)와 **Coursera Coach**(전이 가능 스킬 기반 학습 경로). 둘 다 1회성 탐색이며, 결과 뒤의 "매주 무엇을 할지"와 지속 관리가 없다. Teal·Careerflow·Kickresume·Jobscan·Final Round는 "이미 정한 직무에 지원하는 효율"에 집중하며 전환 자체를 다루지 않는다. B2B(Fuel50·SkyHive·Eightfold)는 스킬 인접성 엔진을 갖고 있으나 고용주가 고객이고 개인은 접근 불가.
- **축 2 — 비판단적 주간 습관 루프**: Rocky.ai(일 5분), Headspace Ebb(동기면담), Finch·Fabulous가 설계 레퍼런스. 그러나 모두 멘탈·습관 도메인이며 커리어 전환 액션을 다루지 않는다. BetterUp Grow(캘린더 프롬프트·Slack 코칭)가 커리어+케이던스를 결합하지만 기업 직원 전용 B2B.
- **축 3 — 동의 기반 라이프로그 "브레인"**: Limitless·Humane은 하드웨어 라이프로그로 갔다가 각각 Meta 인수(2025.12)·HP 자산 매각(2025.02)으로 소비자 제품이 종료됐다. 소프트웨어 쪽(Me.bot, Personal.ai, Khoj, Mem)은 "세컨드 브레인"이지만 커리어 목적이 아니고 MCP로 제3자에게 개방하지 않는다. ChatGPT·Claude 커넥터는 플랫폼 내부 컨텍스트일 뿐 외부 호출 대상이 아니다.
- **축 4 — B2C 무료/저가 획득 + 제3자 API 과금**: 선례는 Datacoup(종료), Streamr/Swash(크립토 니치), Brave(데이터 아닌 광고 주의 판매). "사용자 동의한 개인 컨텍스트를 브랜드가 토큰 단위로 호출·과금"하는 모델을 운영 중인 회사는 조사 범위에서 확인되지 않았다. Personal.ai가 "페르소나를 기업에 제공"으로 가장 근접하나 사용자 본인의 비즈니스용이지 제3자 브랜드 과금이 아니다.

**가장 가까운 단일 경쟁자**: 직접 축에서는 Google Career Dreamer(무료·거대 유통력이 위협), 통합 비전 측면에서는 BetterUp(코칭+캘린더+B2B 과금, 다만 B2B2C). VC가 "Google이 하면?"을 물을 것이므로 Career Dreamer가 1회성·미국 한정·습관 루프 없음·B2B 없음이라는 점을 근거로 답변 준비 필요.

## B2C→B2B 데이터 수익 모델 선례

| 선례 | 모델 | 결과 | 시사점 |
|---|---|---|---|
| Datacoup (2012~2019) | 사용자 SNS·카드 데이터 피드를 익명화해 브로커에 판매, 사용자에 월 ≤$8~10 지급 | 2019.11 서비스 종료(단일 출처) | 개인 원시 데이터의 단가가 너무 낮아 B2C 보상도, B2B 수요도 임계치 미달 |
| Streamr Data Unions / Swash (2020~) | 브라우징 데이터 풀링 → 마켓플레이스 판매 → DATA 토큰 분배 | 생존하나 크립토 니치 | 토큰 인센티브만으론 메인스트림 수요 창출 실패 |
| Brave Rewards / BAT | 데이터는 디바이스에 두고 "주의(광고 노출)"만 판매 | 운영 중 | 데이터 반출 없는 수익화가 규제·인식 리스크를 피함 — 우리 MCP도 "원시 데이터 반출 없이 추론 결과만 응답" 구조가 유리 |
| Inflection Pi | 무료 B2C 컴패니언 → 2024.03 엔터프라이즈 API 피벗(MS $650M 라이선스) | B2C 종료 수준 | "B2C 무료로 모델·관계 축적 후 B2B 전환"은 가능하나 B2C 제품 자체는 희생됨 |
| BetterUp / Headspace / Noom | B2C 인지도 + 고용주·보험 B2B2C 과금 | 생존·대형 | 검증된 경로는 "데이터 판매"가 아니라 "고용주가 직원 혜택으로 구매" |
| Limitless / Humane | 라이프로그 하드웨어 B2C | 각각 Meta·HP로 인수, 소비자 기기 종료 | 라이프로그 자산은 빅테크가 원함 → 출구는 있으나 독립 B2B 수익 증명 사례 없음 |

**규제·VC 리스크 3가지**
1. **CCPA/CPRA "판매" 정의**: "금전 또는 기타 유가 대가"를 받고 제3자에 개인정보를 공개하면 "sale". 토큰 과금 MCP 호출은 정의상 판매에 해당할 가능성이 높아 "Do Not Sell or Share" 링크·옵트아웃·16세 미만 옵트인 등 의무 발생. 출처: https://www.zengrc.com/blog/whats-the-definition-of-sale-under-the-ccpa/ , 법령 §1798.140 원문 확인 권장.
2. **Delete Act(SB 362, 2025 SB 361 개정)**: 캘리포니아 데이터 브로커 등록·2026.08.01부터 45일마다 DROP 삭제요청 처리 의무. 우리는 사용자와 직접 관계가 있어 브로커 정의를 피할 여지가 있으나, 우리 API를 쓰는 브랜드 측이 브로커 의무를 질 수 있고 "브로커처럼 보인다"는 인식 자체가 리스크. 출처: https://morganlewis.com/blogs/sourcingatmorganlewis/2023/11/california-enacts-the-delete-act
3. **동의·인식 리스크**: 한국 개인정보보호법은 제3자 제공에 별도 동의(목적·수령자·항목 명시)를 요구하며(법령 원문 확인 필요), EU GDPR도 목적별 동의가 필요. VC 관점에서는 "사용자 데이터를 브랜드에 판다"는 한 줄이 Datacoup식 실패 서사와 즉시 연결됨. 대응: (a) 원시 로그 반출 없이 추론 결과·추천만 응답, (b) 호출 단위 사용자 동의 로그, (c) 수익 일부를 사용자에 환원(Brave식) — 피치에서 명시 권장.

## 피치용 포지셔닝 2x2

- **X축: 개인 데이터 깊이** — 왼쪽 "이력서·프로필 수준" ↔ 오른쪽 "전체 라이프로그(캘린더·메시지·웨어러블·노트)"
- **Y축: 행동 변화 지속성** — 아래 "1회성 산출물(이력서·맵·면접)" ↔ 위 "주간 습관 루프(체크인·비판단)"

| | 데이터 얕음 (이력서·프로필) | 데이터 깊음 (라이프로그) |
|---|---|---|
| **습관 루프 있음** | Rocky.ai, Headspace Ebb, Finch, Fabulous (커리어 아님) · BetterUp Grow (B2B, 캘린더 부분) · Pathrise(종료) | **Second Draft (목표 위치, 현재 비어 있음)** |
| **1회성 산출물** | Google Career Dreamer, Coursera Coach, Teal, Careerflow, Kickresume, Jobscan, Final Round, Wonsulting, LinkedIn AI 코치 | Me.bot, Personal.ai, Khoj, Mem, ChatGPT/Claude 커넥터, Limitless(종료) (커리어 아님) |

피치 문장: "왼쪽 아래는 붐비고(이력서 AI), 오른쪽 아래는 빅테크가 인수 중(라이프로그), 왼쪽 위는 멘탈헬스가 증명했다(습관 루프). 오른쪽 위 — '내 삶 전체를 아는 커리어 습관 에이전트' — 는 비어 있고, 그 자리에서만 제3자 API 과금이 성립한다."

## 요약

1. 전문성 전이형 커리어 경로 + 비판단 주간 습관 루프 + 동의 기반 라이프로그 MCP 브레인 + 제3자 토큰 과금을 모두 결합한 회사는 조사 범위(40여 곳)에서 확인되지 않음.
2. 직접 축 최근접은 Google Career Dreamer(무료·1회성·미국 한정)와 Coursera Coach, 통합 비전 최근접은 BetterUp Grow(캘린더·Slack 코칭, 그러나 B2B 전용, 2021 밸류 $1.73B).
3. 습관 루프 설계는 Rocky.ai·Headspace Ebb·Finch에서 차용 가능하며 커리어 도메인에는 아무도 적용하지 않음.
4. 라이프로그 B2C는 하드웨어(Limitless→Meta, Humane→HP)가 소비자 제품으로 실패·흡수됐고 소프트웨어(Me.bot $5M seed+, Personal.ai $7.8M seed+)는 커리어·외부 API 개방이 없음.
5. "개인 데이터 B2B 판매" 선례는 Datacoup 종료·Streamr 니치로 약하므로, 피치는 "데이터 판매"가 아니라 "원시 데이터 반출 없는 추론 API + 호출 단위 동의 + 수익 환원"으로 프레이밍하고 CCPA 'sale' 정의·Delete Act·국내 제3자 제공 동의를 선제적으로 언급해야 함.
