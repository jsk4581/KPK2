# PRD — 2026-10-24
버전: v1 (11:30)

1. 사용자는 생성형 AI 때문에 의뢰가 줄어든 경력 3–10년의 미국 프리랜서 카피라이터 한 명입니다.
2. 이 사람은 쌓아 온 전문성을 어디에 다시 쓸 수 있는지 모르고 혼자 준비하다 중간에 멈추기 때문에 불편합니다.
3. 이 도구의 핵심 행동은 경력·고민·관심사를 전문성이 이어지는 커리어 경로 3개와 이번 주 행동 3개로 바꾸는 것 하나입니다.
4. 경력·고민·관심사 텍스트를 넣으면 전문성이 이어지는 경로 3개와 이번 주 행동 3개를 보여줍니다.
5. 오늘은 생체·센서 데이터 수집, Notion·클라우드 연동, SNS·커뮤니티 기능을 하지 않습니다.
6. 입력칸에 직접 친 텍스트로 경로 3개가 나오고 하나를 고르면 이번 주 행동 3개와 Not today 응답까지 배포 URL에서 작동하면 완료입니다.

## C·U·T

Clear: PASS — "카피라이터인데 클라이언트가 ChatGPT를 쓴다" 한 줄이 미션 문장(AI로 사라질 직업)과 겹쳐 10초 안에 사용자와 불편이 읽힌다
Usable: PASS — 텍스트 3칸 입력 → 경로 카드 3장 → 이번 주 행동 3개와 Not today 응답이 화면 3장으로 보인다
Tiny: PASS — LLM 호출 1회(경로·12주 아크·이번 주 행동을 JSON 한 번에) + 체크인은 클라이언트 로직 + 샘플 응답 JSON 폴백이라 G3 13:00까지 끝난다
