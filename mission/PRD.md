# PRD — 2026-10-24
버전: v2 (12:25)

1. 사용자는 생성형 AI 때문에 의뢰가 줄어든 경력 3–10년의 미국 프리랜서 카피라이터 한 명입니다.
2. 이 사람은 쌓아 온 전문성을 어디에 다시 쓸 수 있는지 모르고 혼자 준비하다 중간에 멈추기 때문에 불편합니다.
3. 이 도구의 핵심 행동은 사용자의 경력과 쌓인 라이프로그를 읽어 전문성이 이어지는 커리어 경로 3개와 지금 상태에 맞춘 이번 주 행동 3개로 바꾸는 것 하나입니다.
4. 시뮬레이션 라이프로그와 경력 텍스트를 넣으면 경로 3개, 이번 주 행동 3개, 진척과 이탈 위험을 보여줍니다.
5. 오늘은 실제 생체·센서·개인 데이터 수집, Notion·클라우드 연동, SNS·커뮤니티 기능을 하지 않습니다.
6. 배포 URL에서 샘플 페르소나의 라이프로그 카드 또는 입력칸으로 경로 3개가 나오고 하나를 고르면 이번 주 행동 3개와 Not today 응답이 이동만 하고 삭제 없이 작동하면 완료입니다.

## C·U·T

Clear: PASS — "카피라이터인데 클라이언트가 ChatGPT를 쓴다" 한 줄과 미리 쌓인 라이프로그 카드가 미션 문장(AI로 사라질 직업)과 겹쳐 10초 안에 사용자와 불편이 읽힌다
Usable: PASS — 라이프로그 카드(시뮬레이션) → 경로 카드 3장 → 이번 주 행동 3개와 Not today 응답 → Progress 탭이 모바일 화면 한 줄기로 보인다
Tiny: PASS — 판단은 logic.js 결정론 함수, LLM은 1회(폴백 JSON으로도 동작), 라이프로그는 합성 JSON 하나라 P0(경로 → 주 3 → Not today)가 G3 13:00까지 끝나고 P1·P2는 잘라도 P0가 남는다
